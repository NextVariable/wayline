# 45 城商务与交通图层核对

本轮用官方规划、监管或运营资料确认商务地点的身份，再按城市、名称和高德分类核对地图落点。区域太大或找不到可靠中心点时，用有证据的办公楼或道路作为参考，界面明确显示所选地标。会展场馆保留为独立点位。

铁路采用逐城维护的主要客运站名录，参考[铁路 12306 客运站名](https://kyfw.12306.cn/otn/resources/js/framework/station_name.js)和地方运营资料。名单兼顾市中心、主要高铁站与空铁换乘站。机场依据[民航局机场客运吞吐量表](https://www.caac.gov.cn/XXGK/XXGK/TJSJ/202602/t20260226_230119.html)和机场官方资料核对。地方资料与地图类别有冲突时，优先确认设施身份，再核对坐标。例如，大兴机场站是航站楼下的铁路站，与北京大兴站分别上图；澳门机场采用[机场官网](https://www.macau-airport.com/cn/contact-us)指向的客运大楼，替换旧的机场参考坐标。

武汉北车站等货运站、站口和停车设施已排除。长沙西站和厦门翔安机场仍在建设阶段，本次不作为在营枢纽显示。呼和浩特本次核对时使用白塔机场，盛乐机场的正式换场需根据运营方通知复核。苏州、东莞当前图层仅展示本地客运铁路等交通设施，西安、西宁、拉萨的机场按实际所在行政区定位。
