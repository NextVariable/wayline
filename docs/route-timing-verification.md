# 交通耗时核对

基线为 RC.5 的 `0a8a8ab`。只覆盖中国大陆现有高德路线，以及 Today、Trips、Copilot 的使用方式。

## 接口和计算

| 模式 | 高德 Web 服务 | 参数及时间口径 |
| --- | --- | --- |
| 地铁公交 | `/v5/direction/transit/integrated` | 策略 0、起终城编码、`originpoi/destinationpoi`。使用路段计划出发的北京时间 `date` 和 `time`。已明确的路段出发时间优先，普通相邻日程使用上一场可离开时间。结束待确认时不猜出发时间。 |
| 步行 | `/v5/direction/walking` | `origin_id/destination_id`。读取路线预计时间。 |
| 打车/自驾 | 共用 `/v5/direction/driving` | 策略 32、`origin_id/destination_id`。只消费查询时的驾车估算。不会将计划出发时间作为普通驾车接口的预测参数。 |

请求 `show_fields=cost,polyline`。读取首个推荐方案的 `cost.duration`（秒）和 `distance`（米）。分钟数向上取整一次。公交直接使用整段方案总耗时，已包含方案内步行、等车、换乘，不用分段耗时叠加。地点搜索保留高德 POI、城市编码与可用的入口/出口坐标。路径请求优先用可信到达点，有 POI 但没有通行坐标时带上 POI ID；两者都缺少时沿用坐标，不猜门口。高德链接使用同一套可用坐标。 [路线规划 2.0](https://lbs.amap.com/api/webservice/guide/api/newroute) · [高德地点字段](https://lbs.amap.com/api/webservice/guide/api-advanced/search)

`门到门估算 = 高德耗时 + 交通方式额外预留`。默认等车 8 分钟，取车与停车 10 分钟，两项为估算，可在路线详情分别调整（当前设备工作区）。公交额外等车为 0。安全缓冲单独扣除。建议最迟出发时间是下一项开始时间减门到门耗时及安全缓冲。

按出发的真实时刻判断未来，包含同一天稍后的路段。出发前查询的记录不会随时钟推进自动变成当前数据。网页可见、在线时，每分钟检查距出发 30 分钟内且下一场尚未开始的可见路段；复用分模式缓存与现有限速。Copilot 用同一计划出发与路线服务。数值回复由工具结果生成，模型文本不能覆盖证据。缺少已确认的公交出发时刻时先确认对应日程。
